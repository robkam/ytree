YtreeNova rebrand summary
=========================

Changed project branding from Ytree to YtreeNova while keeping the CLI/manpage
name as ytnova/ytnova(1).

Key changes:
- Build output is now build/ytnova and the generated manpage is build/ytnova.1.
- Manpage source moved to etc/ytnova.1.md; docs/USAGE.md was regenerated from it.
- Default runtime files now use the clean YtreeNova names:
  - ~/.ytnova
  - ~/.ytnova-hst
  - ~/.ytnova-<pid>.chdir
- Default profile source moved to etc/ytnova.conf and generated template text now names YtreeNova/ytnova.
- Public docs, AI/tooling docs, tests, scripts, workflows, issue links, and build/install instructions now point to YtreeNova/ytnova and the ytreenova repository slug.
- Header/test helper filenames were renamed from ytree* to ytnova* where they represent project-local interfaces.
- Historical references to the upstream original Ytree project were intentionally preserved in README, AUTHORS, and the manpage.

Compatibility notes:
- Legacy ~/.ytree, ~/.ytree-hst, and ~/.ytree-<pid>.chdir are not used after this rebrand; this is an intentional clean separation.
- No ytree command wrapper/symlink was added; the executable is ytnova.
- GitHub redirects from the old repository URL currently resolve to https://github.com/robkam/ytreenova.
