   File: scripts/check_appstate_contract.py:2888-2896; src/core/main.c:1116-1124; tests/test_appstate_contract_guard.py:5096-5111,6655-6656
   Evidence: The document guard and startup guard classify no-write/read-only shims by free-text substring search. Any write_permission containing "never write", "no write", "do not write", "read-only", or "read only" is treated as not write-capable, and _validate_shim_owner_field_refs then skips target declared_write_set coverage at scripts/check_appstate_contract.py:2946-2947. Runtime has the same bypass pattern in AppStateCompatibilityShimWriteCapable. A probe against the staged code returned no failures for a write-capable permission phrase with an outside owner ref: `Do not write stale mirror directly; write only from transition commit after canonical state changes.` with owner_field_refs `["field.outside"]` and target declared_write_set `["field.inside"]` produced `[]`. The added tests only cover the positive no-write allowance (`Never write authoritative selection...`) and static presence of the C markers; they do not prove that mixed/negated write-capable text still gets write-set enforcement.
   Impact: This violates the acceptance criterion that no-write/read-only classification be narrow enough not to become a bypass for write-capable text. Future shim metadata can accidentally or intentionally include a marker phrase while still describing transition writes, and both the document guard and startup validation will fail open for owner refs outside the target transition write set.
   Concrete fix: Replace free-text classification with a structured metadata field such as `write_capability: "write-capable" | "read-only-projection" | "no-write"`, or require an exact bounded allow-list of complete write_permission strings/ids for no-write shims. Mirror the same classifier in runtime from generated/declared metadata, not ad hoc C substring checks. Add negative tests for mixed write-capable text containing each marker phrase and runtime/startup assertions for the same fail-closed behavior.
