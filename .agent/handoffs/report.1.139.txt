Summary of changes
- Added `dispatch_surface_refs` to action and event coverage docs, with runtime metadata fields/counts in `AppStateActionCoverageMetadata` and `AppStateEventCoverageMetadata`.
- Extended `src/core/appstate_actions.c` action/event runtime tables to carry dispatch-surface refs and added three missing dispatch-surface registry entries for uncovered transitions:
  - `surface.command-completion-dispatch`
  - `surface.volume-menu-selection`
  - `surface.panel-anchor-rebind`
- Extended `scripts/check_appstate_contract.py` to fail closed when action/event dispatch refs are missing, empty, malformed, duplicate, unknown, or mapped to a surface whose `transition_id` mismatches the coverage record.
- Extended runtime-vs-doc drift checks so action/event runtime coverage dispatch refs must match docs.
- Extended startup readiness in `src/core/main.c` with shared `AppStateDispatchSurfaceRefsReady(...)` validation so malformed action/event dispatch refs abort readiness.
- Expanded contract tests and runtime-source fixture generation to cover action/event dispatch refs, runtime drift, and startup/readiness evidence.
