AppState action lookup unit report

Files changed
- include/ytree_appstate_actions.h: added read-only AppState action transition metadata API.
- src/core/appstate_actions.c: added static YtreeAction-to-transition/category lookup table and fail-closed lookup function.
- scripts/check_appstate_contract.py: added runtime lookup parsing and validation against the YtreeAction enum, docs/appstate_action_coverage.json, and docs/appstate_transition_matrix.json; added --action-runtime override.

- scripts/check_module_boundaries.py: registered ytree_appstate_actions.h as a core header so the new src/core module passes the existing boundary guard.
