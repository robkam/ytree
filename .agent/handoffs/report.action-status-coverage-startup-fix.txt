Root cause
- `src/core/appstate_actions.c` validated foundation metadata through `AppStateKnownFoundationStatus()`.
- That helper incorrectly accepted only `covered_by_transition_record`, while owner fields, invariants, generation domains, and diff harness entries in the repository use `documented_foundation_only`.
- Startup readiness in `src/core/main.c` depends on validated invariants, generation domains, and diff harness coverage when checking `AppStateEventCoverageReady()` and `AppStateActionCoverageReady()`.
- As a result, foundation metadata looked present through raw lookup helpers but failed validation when readiness walked the validated registries, so version startup aborted before printing the version string.
