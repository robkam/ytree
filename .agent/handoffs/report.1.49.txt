Summary of changes
- Added read-only AppState action-coverage runtime metadata APIs: count, index accessor, and YtreeNovaAction lookup.
- Added runtime action-coverage rows mirroring docs/appstate_action_coverage.json fields: action enum, action name, transition_id, category, owner, declared_write_set, boundary_status, and migration_notes.
- Extended startup invariant validation for full enum coverage, duplicate/shape checks, valid transition references, non-empty owner/write-set/boundary/migration fields, consistency with AppStateActionTransitionLookup, write-set consistency with transition metadata, and fail-closed invalid/out-of-range lookups.
- Extended the Python AppState contract guard to parse and compare runtime action-coverage metadata, including malformed row/list detection, doc drift, invalid transition linkage, runtime transition registry linkage, action-transition drift, missing/extra/duplicate actions, and unknown enum members.
- Added focused guard/runtime tests for action-coverage lookup and malformed/drifted registry behavior.
