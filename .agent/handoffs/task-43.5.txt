## Final design

- Markdown is parsed into visible text and bounded `UIHelpPopupSpan` metadata; raw Markdown and control markers never enter wrapped display text.
- Each span carries its visible range and semantic role. The renderer consumes those explicit ranges for links, selected links, backticked terms, and attention styling.
- Wrapping uses visible text width and keeps complete link spans together where they fit.
- Inline links have explicit target metadata and ordered selection state. Down stops after the final link and scrolls; Up re-enters in reverse order; Right/Enter opens the target and Left restores history.
- Existing related-help/footer links and contextual-help list navigation retain their prior paths.
